# Security policy

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** action in the Security tab so a
report can be reviewed privately before public disclosure. Include the affected
revision, impact, and minimal reproduction steps.

Never attach Apple credentials, signing keys, provisioning profiles, pairing
files, device identifiers, commercial game images, firmware, keys, or user save
data. Redact local paths and account names from logs.

Public issues are appropriate for ordinary build failures and compatibility
bugs after sensitive details have been removed.

## Scope

Security reports for inherited Dolphin or DolphiniOS behavior may need to be
coordinated with the applicable upstream project. This community build does not
provide an alternate security boundary, code-signing service, game source, or
JIT service.
